# 리더에게 데모 웹사이트 파일 요청하기

코딩 지식이 없는 리더가 Claude(웹/앱)로 데모 웹사이트를 만든 경우, "파일을 보내달라"고 하면 본인도
어떻게 해야 할지 모를 수 있음. 아래 2단계로 진행.

---

## 1단계 — 리더에게 보낼 메시지 (카톡/디스코드 등으로 그대로 전달)

> [리더님]! 만들어주신 데모 웹사이트 관련해서 부탁 하나 드려도 될까요? 🙏
>
> 웹사이트를 만드셨던 그 Claude 대화창을 다시 열어서, 아래 "Claude에게 보낼 프롬프트" 전체를
> 그대로 복사해서 붙여넣고 보내주시면 돼요. 그러면 Claude가 웹사이트를 만드는 데 쓰인 파일들을
> 전부 정리해서 답해줄 거예요.
>
> 그 답변이 나오면 화면을 전체 캡처하시거나, 답변 내용을 통째로 복사해서 저에게 전달해주시면
> 됩니다. 코드 내용을 이해하실 필요는 전혀 없어요 — 그냥 복사-붙여넣기만 해주시면 충분해요!

---

## 2단계 — 리더가 자신의 Claude 대화에 그대로 붙여넣을 프롬프트

```
이 대화에서 우리가 만든 웹사이트를 구성하는 모든 파일을 하나도 빠짐없이 정리해서 알려줘.
아래 순서와 형식을 그대로 지켜줘.

1. 지금까지 이 대화에서 만들어졌거나 수정된 파일/아티팩트를 전부 나열해줘.
   (예: index.html, style.css, script.js 등. 만약 하나의 HTML 파일 안에 CSS와 JS가
   전부 들어있는 구조라면, 그것도 "파일 1개, 그 안에 스타일/스크립트 포함"이라고 명시해줘.)

2. 각 파일마다 가장 최신(최종) 버전의 전체 내용을 코드 블록으로 보여줘.
   절대로 요약하거나, 일부만 보여주거나, "...이하 생략...", "...나머지는 동일..." 같은
   생략을 하지 마. 처음부터 끝까지 전체 코드를 그대로 다 보여줘야 해.
   이 코드를 복사해서 다른 곳에 그대로 붙여넣었을 때 지금과 똑같이 작동해야 하니까,
   빠지는 부분이 있으면 안 돼.

3. 이 웹사이트가 사용하는 외부 리소스가 있다면 전부 목록으로 알려줘.
   (예: CDN으로 불러온 스크립트/라이브러리, 웹폰트, 외부 이미지 링크, 연결된 API 등)

4. 코드 안에 API 키, 비밀번호, 토큰처럼 민감한 정보가 그대로 하드코딩되어 있는지
   확인해서, 있다면 정확히 어느 파일 몇 번째 줄쯤에 있는지 알려줘.

5. 마지막으로, 이 웹사이트가 지금 어떤 기능을 하는지, 그리고 내가 이 파일을 받아서
   실행하려면 어떻게 해야 하는지(예: 그냥 파일을 더블클릭해서 브라우저로 열면 되는지,
   별도 서버나 프로그램이 필요한지) 비개발자도 이해할 수 있게 쉬운 말로 설명해줘.
```

## 참고
- Claude.ai(웹)의 "Artifacts" 기능으로 만든 경우, 화면 우측 아티팩트 패널에 다운로드
  버튼이 있을 수도 있음 — 리더에게 "혹시 오른쪽에 다운로드 버튼 보이시나요?"라고
  먼저 물어봐도 좋음. 안 보이면 위 프롬프트로 텍스트 형태로 받으면 됨.
- 4번 항목(민감정보 하드코딩 확인)은 특히 중요 — 만약 Supabase URL/anon key처럼
  공개돼도 안전한 값이 아니라 진짜 비밀키(secret key)나 개인 API 키가 코드에 그대로
  박혀있다면, 그 파일을 그대로 공개 저장소에 올리면 안 되니 반드시 확인 필요.
